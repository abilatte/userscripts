# 起点小说屏蔽工具

用于按书籍 ID 精确屏蔽不感兴趣的小说，并提供可视化管理面板。

## 功能特性

- 按书籍 ID 精确屏蔽，避免标题改动导致误判
- 支持列表页快速屏蔽
- 支持作品详情页直接屏蔽 / 取消屏蔽
- 自动记录屏蔽时间
- 提供管理面板，支持搜索、排序、分页、批量操作
- 支持屏蔽数据导入 / 导出

## 使用说明

### 列表页

- 每本书右侧会出现屏蔽按钮。
- 点击后会立即将该书加入屏蔽列表。
- 已屏蔽作品会从当前视图中隐藏。

### 作品详情页

- 在阅读 / 加书架等按钮附近显示快捷屏蔽按钮。
- 可直接切换屏蔽状态。

### 管理面板

- 通过 Tampermonkey 菜单命令打开管理面板。
- 支持按书名或书籍 ID 搜索。
- 支持按时间或标题排序。
- 支持批量取消屏蔽、导出、导入。
