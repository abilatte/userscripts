# 起点小说屏蔽工具

用于按书籍 ID 精确屏蔽不感兴趣的小说，并提供可视化管理面板。

## 功能特性

- 按书籍 ID 精确屏蔽，避免标题改动导致误判
- 支持列表页快速屏蔽
- 全部作品页（图文与文字模式）均支持内置无缝翻页
- 支持作品详情页直接屏蔽 / 取消屏蔽
- 自动记录屏蔽时间
- 提供管理面板，支持搜索、排序、分页、批量操作
- 支持屏蔽数据导入 / 导出

## 使用说明

使用支持 Web Locks 的浏览器和 Tampermonkey。从 v2.3 升级后，请刷新已打开的起点标签页，确保所有标签页都用同一版本写入。旧版屏蔽列表和同步设置会自动迁移。

### 列表页

- 每本书右侧会出现屏蔽按钮。
- 点击后会立即将该书加入屏蔽列表。
- 已屏蔽作品会从当前视图中隐藏。
- 滚动到列表底部时，会按当前筛选和排序自动加载下一页（图文模式可见书目跨页连续排成两列，文字模式连续追加表格行），加载页码显示在列表底部。
- 遇到网络错误、超时或服务器故障时，等约 1.5 秒后在列表底部继续向下滚动即可重试，每页最多自动重试两次。失败后始终可以手动重试或直接打开那一页。
- 视口右侧显示当前已加载及已隐藏的书目统计，并提供「临时显示」「按分类屏蔽」以及「自动翻页 / 停止翻页」快捷按钮。
- 点右侧「按分类屏蔽」，会直接打开管理面板的「分类规则」标签页，选择大类，或再选择具体小类。可从「屏蔽已加载的书」和「添加自动屏蔽规则」中选择。
- 批量操作把当前已加载、且符合选择的书按 ID 加入屏蔽列表，参与原有的导入导出和 GitHub 同步。自动规则保存在当前浏览器，适用于之后遇到的同类书，可在同一面板单独移除。
- 内置无缝翻页默认开启。可在面板「设置与同步」标签页中配置翻页延迟（毫秒）、限流（HTTP 429 / 404）自动重试等待秒数、自动翻页目标页数（`0` 为一直翻到结尾）及打开页面自动开始，也可随时开关无缝翻页，修改后立即生效。
- 如果在「全部作品」页使用 Pagetual 等第三方翻页脚本，可以关闭内置无缝翻页来避免重复加载。

### 作品详情页

- 在阅读 / 加书架等按钮附近显示快捷屏蔽按钮。
- 可直接切换屏蔽状态。

### 管理面板

- 通过 Tampermonkey 菜单中的单个入口「管理屏蔽与设置」打开聚合管理面板，内含三个标签页：
  - **屏蔽列表**：按书名 / ID / 大小分区筛选，按时间或标题排序，分页、批量取消屏蔽及单条移除撤销。
  - **分类规则**：管理按分类自动屏蔽规则，或在「全部作品」页批量屏蔽当前已加载的同类书。
  - **设置与同步**：开关内置无缝翻页、配置 GitHub 多设备同步、导入/导出备份、清空数据及重置版本锚点（仅在清空或重装脚本数据后提示无法保存时使用）。

### 多设备同步（可选）

屏蔽列表可以保存到你自己的 GitHub 仓库，在多台设备之间自动同步。

1. 在 GitHub 新建一个**私有**仓库用来存放数据。
2. 在 GitHub 的 Settings → Developer settings → Fine-grained tokens 生成令牌：Repository access 只选这个仓库，Permissions 里把 Contents 设为 Read and write。
3. 打开「管理屏蔽与设置」→「设置与同步」，填入仓库（`用户名/仓库名`）、文件路径和令牌，点「保存并同步」。
4. 在其他设备上重复第 3 步。

同步文件必须是按书籍 ID 保存的屏蔽列表，也支持旧版仅保存书名的记录。文件格式有误时，同步会停止并提示路径。

之后脚本会在打开或切回页面时拉取最新列表，在本机有改动后约 30 秒自动上传。两台设备各自的新增和取消屏蔽都会保留。令牌只保存在脚本管理器的本地存储中。

## 本地开发

使用 Node.js 24 或更新版本，在本目录运行：

```sh
npm ci
npm run build
npm test
npm run check:build
```

- `src/core/` 保存书单数据、跨标签页存储和 GitHub 同步逻辑。
- `src/pages/` 保存起点列表、图文翻页和详情页逻辑。站点选择器集中在 `src/config.mjs`。
- `src/ui/` 保存管理面板、导入导出、提示条和样式。脚本头部在 `src/userscript.meta.txt`。

修改源码后运行 `npm run build`，将生成的 `qidian-novel-blocker.user.js` 与源码一起提交。Tampermonkey 继续从原地址安装或更新这个单文件。`npm run check:build` 可以检查产物是否与源码一致。
