# nHentai Pro

![Version](https://img.shields.io/badge/Version-2.8.2.18-ed2553?style=flat-square)
![License](https://img.shields.io/badge/License-GPLv3-blue?style=flat-square)

给 [nhentai.net](https://nhentai.net/) 加上**中文搜索、标签汉化、封面预览和卷轴阅读**。装好即用，所有选项都在导航栏的「设置」里。

- **用中文搜标签**：输入「黑丝」就能联想并搜到对应的英文标签，不用记英文名
- **标签全站汉化**：基于 [EhTagTranslation](https://github.com/EhTagTranslation/Database) 社区词库，4 万余条译名
- **不点进去也能预览**：封面上直接翻看内页，显示总页数和完整标签
- **一口气读完**：卷轴阅读模式连续滚动，记住读到第几页
- **少翻页、少干扰**：无限滚动、语言筛选、黑名单彻底隐藏

## 功能

### 搜索
- **中英文联想**：边输入边提示，带「标签 / 作者 / 角色」等分类角标
- **中文直搜**：搜索时自动把中文标签换成站点能识别的英文标签语法
- **片段匹配**：只输入一部分也能联想到完整词条，如 `sousou no` → `sousou no frieren`
- **快捷标签栏**：一键追加原作、角色、语言、页数等搜索条件
- **排除搜索**：`Shift + 点击` 联想词或快捷标签，自动加 `-` 排除
- **与官方联想共存**：可选自动兼容、只用本脚本联想或关闭

### 汉化
- **界面汉化**：导航、设置、个人页、评论区等常见文字
- **标签汉化**：四种显示方式——原文优先、译文优先、仅译文、仅原文
- **上传时间**：相对时间、绝对时间或两者同时显示
- **词库本地缓存**：只有首次安装需要等待下载，之后打开即用，后台自动检查更新

### 列表浏览
- **页数徽标**：封面右上角显示总页数
- **悬停预览**：鼠标移到封面上，点左右两侧或拖动底部进度条翻看内页，也可以用 `←` / `→`
- **弹窗预览**（桌面端，可选）：用更大的独立窗口预览，可调大小和位置
- **标签速览**：悬停封面左上角「标签」，查看这本的完整标签
- **无限滚动**：滑到底自动加载下一页，地址栏同步页码；加载失败会自动退避重试，连续失败后改为点击重试
- **阅读进度角标**：读过的本子在封面上显示读到第几页
- **语言筛选**：导航栏多选只看中文 / 英文 / 日文

### 阅读
- **卷轴阅读模式**：详情页点「卷轴阅读」，整本连续滚动
- **进度记忆**：再次打开从上次的位置继续，按钮直接显示「继续阅读 12/30」
- **调节**：缩放与图片间距可随时修改，`Ctrl + 滚轮` 或触屏双指实时缩放
- **适应方式**：适应宽度 / 适应高度一键切换
- **跳页**：拖动右侧进度条快速定位，或在左侧工具栏输入页码
- **自动滚动与全屏**：速度可调，点击画面即停
- **返回键退出**：按浏览器返回（或手机返回手势）先退出阅读，不会离开详情页
- **失败重试**：某页加载失败时，点击该页即可重新加载

### 黑名单与净化
- **彻底隐藏**：黑名单本子直接不显示，不留半透明占位
- **快捷屏蔽**（需登录）：详情页每个标签旁一键加入或移出账号黑名单
- **黑名单页筛选**：账号设置的黑名单页按类型筛选，并显示数量
- **界面净化**：隐藏导航栏里的 AI 推广入口和社交图标

## 安装与设置

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或兼容的脚本管理器），再安装本脚本
2. 打开 [nhentai.net](https://nhentai.net/)。首次运行会下载汉化词库，视网络约十几秒到半分钟，完成后自动生效
3. 点击导航栏的 **设置** 调整功能，分为「浏览」「翻译」「搜索与筛选」「黑名单」「数据与调试」五页

设置面板可切换中 / 英文界面；保存时只有设置有变化才会刷新页面。「数据与调试」页可以导出、导入设置（含阅读进度，不含 API Key）或恢复默认。

## 常见问题

**标签没有汉化？**
首次安装需要等词库下载完。如果一直没有汉化，打开 设置 → 数据与调试 → **强制更新汉化数据库**，或使用脚本管理器菜单里的同名命令。

**词库更新失败？**
词库从 GitHub（`raw.githubusercontent.com`）下载，网络不通时会自动尝试备用镜像；仍然失败也会继续使用本地已有的词库，不影响汉化。

**中文联想和官方联想叠在一起？**
设置 → 搜索与筛选 → **联想兼容模式**，可改为只用本脚本联想或关闭本脚本联想。

**导航栏里找不到设置按钮？**
使用脚本管理器菜单里的「打开助手设置」，或用「显示/隐藏网页设置按钮」把按钮找回来。

## 隐私与权限

- 跨域请求只有一个：从 `raw.githubusercontent.com` 下载汉化词库；其余请求都发往 nhentai.net 本站
- 设置、阅读进度和词库都只保存在你的浏览器本地
- 为减少重复请求，浏览过的画廊信息（页数、标签等）会在浏览器本地缓存 7 天；可在 设置 → 数据与调试 关闭「本地缓存画廊信息」，关闭时会清空已缓存的数据
- 不会修改你的账号数据，除非你主动使用「快捷屏蔽」（它会修改账号黑名单）
- 可选的 API Key **只**用于本脚本发出的 `nhentai.net/api/v2/*` 请求，不会显示在页面上，也不会拼进网址
