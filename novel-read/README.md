# 小说阅读模式（Tampermonkey 脚本）

在笔趣阁类第三方小说站上提供起点风格的阅读模式。

- 滚动翻页（自动拼接下一章）/ 章节翻页（预加载下一章）
- 目录：本次阅读的章节 + 全部章节（打开阅读模式即在后台获取；读到章节末尾的章节会长期标记为已读）
- 划选正文：「摘录」保存到全局摘录本，可按编号 / 每行一条 / 顿号连接批量复制；「过滤」把选中文字加入本站过滤（只删这段文字）
- 设置 →「过滤」：查看系统规则，增删本站的正则规则（整段删除）和划选过滤文字（只删这段文字），改动立即生效
- 书架：书名、作者从书页读取；同一本书可在多个站点加入（按简体书名 + 作者合并），记录各站上次读到的章节，点击后跳转并直接进入阅读模式
- 换源（工具栏或快捷键 `S`）：列出同一本书在其它已适配站点的来源（书架里已有的 + 自动搜索），显示章节数、与当前站的差值、最新章节、是否有本章；点击直接跳到对应章节并进入阅读模式。站内搜索自动识别站点的搜索表单（GET/POST），也可在站点规则里配置 `search`
- 已读跨站同步：读完的章节按「书名 + 作者」记录标题，在任何站点的目录里同名章节都显示已读
- 设置 →「数据」：导出 / 导入备份（阅读设置、站点与过滤、阅读记录与书架、摘录，可按类勾选）；导入与本机数据合并，不删除已有内容
- 简繁转换：原文 / 简体 / 繁体（opencc-js，两个方向的字典各是一个 `@resource`，分别按需加载）
- 主题、字体、字号、页宽、行间距、段间距
- 站点列表：在设置里添加域名，或在 Tampermonkey 菜单「将本站加入阅读站点」；未适配的站点可点选正文和下一章完成适配，规则可导入导出

内置适配：twkan.com、deqixss.com（正文走接口，见 `src/sites/adapters.ts`）、sudugu.cc（一章多页自动合并）。

## 安装

```bash
npm install
npm run build
```

把 `dist/novel-reader.user.js` 拖进浏览器，或在 Tampermonkey 中新建脚本粘贴内容。

## 开发

```bash
npm run dev
```

`vite-plugin-monkey` 会给出一个安装地址，安装后修改源码会热更新到 Tampermonkey。

```bash
npm test
```

测试用 vitest + happy-dom，覆盖正文提取、分页合并、目录收集、章节匹配、站点规则存储和备份合并；`tests/gm.ts` 是 `GM_*` 的内存实现。

脚本版本号只在 `package.json` 里改，opencc 字典的 CDN 版本跟随安装的 `opencc-js`。

## 结构

| 路径 | 说明 |
|---|---|
| `src/main.tsx` | 入口：站点匹配、入口按钮、菜单、打开阅读器/点选器 |
| `src/sites/builtin.ts` | 内置站点规则 |
| `src/storage.ts` | 设置与站点列表的读写、校验 |
| `src/core/source.ts` | 换源：站内搜索识别、书页解析、章节匹配 |
| `src/backup.ts` | 配置备份的导出、校验与合并导入 |
| `src/core/extract.ts` | 正文/标题/链接识别与清洗（含自动识别） |
| `src/core/loader.ts` | 章节加载、缓存、同标题分页合并（只在有分页迹象时探测下一页） |
| `src/core/toc.ts` | 完整目录获取 |
| `src/core/opencc.ts` | 简繁转换 |
| `src/ui/` | 阅读器、目录、设置、站点管理、点选器（Preact + Shadow DOM）；`useSelection` / `useReaderKeys` 是从阅读器拆出的划选和键盘逻辑 |
| `tests/` | 单元测试 |

内置站点的用户改动（过滤词、编辑过的字段）只按字段保存，脚本更新内置规则时，没动过的字段会跟着更新。

## 站点规则字段

见 `src/types.ts` 中的 `SiteEntry`。常用字段：`content`（正文选择器）、`title`、`next` / `prev` / `tocLink` / `bookLink`（`{ selector?, text? }`，不写 `text` 时按「下一章 / 上一章 / 目录 / 书页」等通用文字匹配；书名从书页的 `og:novel:book_name` → `og:title` → `h1` 读取）、`toc.api`（支持 `{bookId}`）、`remove`、`filters`（段落过滤正则，匹配前会把花体字母还原成 ASCII）、`strip`（划选加入的过滤文字）、`adapter`（内置代码适配器）。
